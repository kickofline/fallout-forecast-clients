# Fallout Forecast Open Protocol

The Open Protocol connects independent clients to Fallout Forecast's dedicated
server. Thin clients send controls and render server snapshots. Full clients
simulate local movement and exchange game RPCs.

Start with the [implementer guide](open-protocol/AGENTS.md) for tier selection,
the specifications, game data, transcripts and validation instructions. Use the
[compact index](open-protocol/llms.txt) for a list of files.
