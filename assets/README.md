Generated by `exporter/export_all.gd` from the Fallout Forecast Godot 4.7.2 repository.
All IDs match `docs/car-bridge-protocol.md` and are indexed in `manifest.json`.

## Godot 3.6 GLES2 Import Expectations

1. **Nearest Texture Filtering (64×64 pixel-art world textures):**
   - All map textures (`asphalt`, `sidewalk`, `pavers`, `grass`, `forest_floor`, `dirt_trail`, `siding`, `wood`, `shingles_teal`, `brick`, `stucco`, `tile`, `quay_steel`, `diamond_plate`, `awning_cyan`, `awning_pink`, `canopy`, `harbor_tide_baked`, and Kenney `colormap` atlases) are exported with glTF `NEAREST` samplers and `REPEAT` wrapping.
   - Godot 3.6's glTF importer imports embedded textures with default `FLAG_FILTER` unless overridden in an import script or at load time. On the Godot 3.6 client, clear `Texture.FLAG_FILTER` (and keep `Texture.FLAG_REPEAT`, optionally enable `Texture.FLAG_MIPMAPS` only if avoiding shimmer; raw retro look uses `flags = Texture.FLAG_REPEAT`) on map textures (except `mist_radial`, which should keep `FLAG_FILTER` for soft radial falloff).
2. **Emissive Strength & Unshaded Materials:**
   - glTF 2.0 `KHR_materials_unshaded` imports into Godot 3.6 as `SpatialMaterial.flags_unshaded = true`.
   - Godot 3.6 clamps glTF `emissiveFactor` to `[0, 1]` and ignores `KHR_materials_emissive_strength`. For neon signs and glowing eyes/cores (`emission_enabled`), setting `emission_energy = 1.5..2.5` (or enabling subtle GLES2 glow if perf allows) reproduces the desktop pop.
3. **Vertex Colors:**
   - Meshes with `COLOR_0` (characters, weapons, props, and `MeshMerge`-batched surfaces) have sRGB-converted linear vertex colors per glTF 2.0. Godot 3.6 automatically enables `vertex_color_use_as_albedo = true` on those primitives.
4. **OpenGL ES 2.0 / PowerVR SGX 544MP Notes:**
   - Avoid real-time shadow maps; use 1 `DirectionalLight` (from `environments.json`) + `Environment` ambient + linear fog (`fog_depth_begin_gles2` / `fog_depth_end_gles2`).
   - Use `maps/pinecrest_low.glb` (103k tris) on SGX 544MP if full `pinecrest.glb` (151k tris) drops below target frame rate.
   - Spawn at most 2–4 nearest `OmniLight`s from `<map>.json`'s `lights` list (or skip dynamic omnis and rely on baked emissive tubes/windows).

## Articulated Hierarchies & Procedural Animation Parameters

All characters face `-Z` forward, `+Y` up (Godot convention). Coordinates are local to each parent pivot.

### 1. Player (`characters/player/<skin>_<color>.glb` & `characters/enemies/turned.glb`)

Source: `player/player_model.gd`

```
<root>
├── Hips            pos = (0, 0.92, 0)
│   ├── Torso       pos = (0, 0.12, 0)
│   │   ├── Head    pos = (0, 0.60, 0)
│   │   ├── ArmL    pos = (-0.30, 0.46, 0)
│   │   │   └── ForearmL  pos = (0, -0.29, 0)
│   │   └── ArmR    pos = (+0.30, 0.46, 0)
│   │       └── ForearmR  pos = (0, -0.29, 0)
│   ├── LegL        pos = (-0.12, -0.06, 0)
│   │   └── ShinL   pos = (0, -0.40, 0)
│   └── LegR        pos = (+0.12, -0.06, 0)
│       └── ShinR   pos = (0, -0.40, 0)
└── WeaponMount     tracks ForearmR local (0, -0.29, 0)
```

**Animation equations (`player_model.gd` lines 242–304):**
- Speed smoothing: `speed_smooth = lerp(speed_smooth, horiz_speed, 1 - exp(-10 * dt))`, `sprinting = speed_smooth > 6.5`
- Clock: `clock += dt * (2.0 + speed_smooth * 1.6)`
- Stride: `stride = clamp(speed_smooth / 5.0, 0.0, 1.3)`; `backwards = -1.0` if local `vel.z > 0.4` else `1.0`
- Legs (`i = 0` L, `i = 1` R, `phase = PI * i`):
  - `Leg[i].rot.x = sin(clock + phase) * 0.7 * stride * backwards`
  - `Shin[i].rot.x = -max(0.0, -sin(clock + phase)) * 1.1 * stride - 0.05`
- Hips bob & downed blend (`down_blend` moves toward `1.0` when `state == "downed"` at `3.0/s`):
  - `bob = abs(sin(clock)) * 0.05 * stride`
  - `breathe = sin(time_s * 2.0) * 0.012`
  - `Hips.pos.y = 0.92 + bob - down_blend * 0.62`
  - `root.rot.z = lerp(0.0, 1.35, down_blend)`
- Aim pitch (`pitch` = camera pitch in radians):
  - `Torso.rot.x = -pitch * 0.35 + (0.25 if sprinting else 0.06) + breathe`
  - `Head.rot.x = -pitch * 0.55`
  - `aim_lift = -pitch * 0.65`
- Arms (standing OK):
  - Shouldered: `ArmL.rot = (1.25 + aim_lift, 0.15, 0.25)`, `ArmR.rot = (1.35 + aim_lift, -0.3, -0.35)`, `ForearmL.rot.x = 0.55`, `ForearmR.rot.x = 0.25`
  - Sprinting: `ArmL.rot = (0.6 + sin(clock)*0.25, 0, 0.2)`, `ArmR.rot = (0.9 - sin(clock)*0.25, 0, -0.25)`, `ForearmL.rot.x = 1.2`, `ForearmR.rot.x = 1.1`
- Turned (`state == "turned"`):
  - `ArmL.rot = (1.4 + sin(clock)*0.15, 0, 0.1)`, `ArmR.rot = (1.4 - sin(clock)*0.15, 0, -0.1)`, `ForearmL.rot.x = 0.2`, `ForearmR.rot.x = 0.3`, `Torso.rot.x = 0.35`, `Head.rot = (0.3, 0, 0.35)`
- Downed crawl (`crawl = sin(time_s * 3.0)`):
  - `ArmR.rot = lerp(ArmR.rot, (2.6 + crawl*0.3, 0, -0.2), down_blend)`
  - `LegL.rot.x = lerp(LegL.rot.x, 0.3 + crawl*0.2, down_blend)`
- Third-person weapon on `WeaponMount`: scale `weapons/view/<id>.glb` by `1.6`, offset by `-basis * Vector3(0.026, -0.045, 0.033)`.

**Shared infected animation equations (`infected_model.gd` lines 462–509):**
- `clock += dt * (freq + horiz_speed * freq_per_speed)`
- `amount = clamp(horiz_speed / 3.5, 0.0, 1.2)`
- Decaying pulses: `hurt` decays at `5.0/s`, `head_kick` at `4.0/s`, `anticipation` (windup) at `2.0/s`, `attack` at `3.0/s`.
- Arms (`phase = 0` for ArmL, `PI` for ArmR):
  - `Arm.rot.x = reach + sin(clock + phase) * arm * amount * 0.4 + anticipation * 1.1 - attack * 1.3 - hurt * 0.7`
  - `Elbow.rot.x = 0.25 + 0.2 * sin(clock * 0.7 + idx) + attack * 0.6`
- Legs (`phase = PI` for LegL, `0` for LegR):
  - `Leg.rot.x = sin(clock + phase) * leg * amount`
  - `Knee.rot.x = -max(0.0, -sin(clock + phase)) * 0.7 * amount - 0.08`
- Torso & Head:
  - `Body.pos.y = abs(sin(clock)) * bounce * max(amount, 0.2)`
  - `Body.rot.z = sin(clock * 0.5) * sway + hurt * 0.22 * hurt_side`
  - `Body.rot.x = lean + hurt * 0.35`
  - `Head.rot.x = head_kick * 0.7`
  - `Jaw.rot.x = 0.18 + 0.1 * abs(sin(clock * 3.1)) + anticipation * 0.4 + attack * 0.3`

### 4. First-Person Weapons (`weapons/view/<id>.glb`)

Sources: `weapons/weapon_holder.gd`, `weapons/item_pose.gd`
- Exact per-weapon `view_position`, `view_rotation_degrees`, `view_scale`, `muzzle`, `sight`, `ads_fov`, `ads_eye_relief`, `pose_action`, `animated_part`, and `support_grip_z` are in `weapons/weapons.json`.
- Walk bob: `bob_phase += dt * speed * 1.6`, `offset = Vector3(sin(bob)*0.012, abs(cos(bob))*0.014, 0) * min(speed, 6.0)/6.0 * (1 - aim*0.85)`.
- ADS placement: when `sight != null`, `ads_pos = Vector3(0, 0, -ads_eye_relief) - view_basis * sight`; else `Vector3(0, -0.12, view_position.z - 0.08)`.
- Kick/recoil: `kick` decays `6.0/s`, `recoil` decays `2.8/s`; adds `pos.z += 0.08*kick`, `rot_deg.x += 6*kick + 8*recoil`.
- Animated child parts (`item_pose.gd`): `Pump` slides `+0.055` on Z; `Magazine` drops `-0.095` on Y; `Cylinder` swings `-0.048` on X and spins; `Bolt` slides `+0.045` on Z; `Barrel` hinges `-0.72` rad on X; `Fan` spins continuously around X; `Dish` spins on Y; `Lid` opens `-1.4` rad on X.
